# Data

Box 14.7.1, Figure 2 is a conceptual schematic. It has no underlying data: no dataset
is read and no numerical value is displayed, so there is no data table to
archive and no input data to cite.

Every box, arrow and label is authored content, drawn directly by
`../code/box14_7_1_fig2.py`. That script's content constants hold the complete
rendered wording.

This folder is kept so every figure package in Section 14.7 has the same
structure. See `../README.md` for what the code does and how to run it.
